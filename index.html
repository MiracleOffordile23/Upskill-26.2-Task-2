What I Learned

1. What does the action attribute do?

The action attribute tells the browser where to send the form data after the form is submitted.

2. What does the method attribute do?

The method attribute tells the browser how the form data should be sent. Common methods are GET and POST.

3. Why is GET commonly useful for a search form?

GET puts the search information in the URL, making it useful for searching and allowing the search URL to be bookmarked or shared.

4. Why might POST be used for a registration form?

POST sends the form data in the request body instead of putting it directly in the URL. It is commonly used when submitting information such as registration details.

5. Does using POST automatically make information secure?

No. POST does not automatically make information secure. HTTPS is needed to encrypt information while it is being sent between the browser and the server.
